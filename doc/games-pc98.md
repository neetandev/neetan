# PC-98 game compatibility

This list contains only the verified compatibility, not the actual one.
Even if a game is not listed here, there is a good chance it runs.
AS and AP machines do not support loading a real BIOS yet. But HLE BIOS and HLE OS should support most games at that era very well.

✅ = Fully working
⚠️ = Has Issues
❌️ = Broken
ⁿ̸ₐ = Not applicable
