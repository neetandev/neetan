# PC/AT (DOS/V) game compatibility

This list contains only the verified compatibility, not the actual one.
Even if a title is not listed here, there is a good chance it runs.

✅ = Fully working
⚠️ = Has Issues
❌️ = Broken
ⁿ̸ₐ = Not applicable

| Title                             | Japanese Title  |     Machine      | Status | Description        |
|-----------------------------------|-----------------|:----------------:|:------:|--------------------|
| Doom (US)                         | Doom            | AT486DX66 (high) |   ✅    | Install in US mode |
| Fermion - Mirai kara no Houmonsha | フェルミオン 未来からの訪問者 | AT486DX50 (low)  |   ✅    |                    |

You can run normal western DOS programs under DOS/V. You might need to change
into the US mode though using the following command: "CHEV US /F".
After this, the text render mode will switch to normal DOS text mode, and
you should have full compatibility with western DOS programs.
