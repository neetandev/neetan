# Contributing / コントリビューション

## Human-written text / 人間が書いた文章

The text of issues and pull requests must be written by a human. Issues and pull
requests generated by bots or AI agents will be closed. Spend at least as much time
writing the text as a reader needs to read it.

IssueとPull Requestの文章は人間が書いてください。ボットやAIエージェントが生成したIssueと
Pull Requestはクローズします。文章を書く時間は、読み手がそれを読むのに必要な時間と同じだけかけてください。

## Compatibility reports / 互換性レポート

The compatibility lists in [`doc/`](doc/) record which titles run on each system.
Reports of working and broken titles are welcome as issues or pull requests.

[`doc/`](doc/)の互換性リストには、各システムで動作するタイトルが記録されています。動作するタイトルと
動作しないタイトルの報告を、IssueまたはPull Requestで歓迎します。

## Language / 言語

Issues and pull requests can be written in English or Japanese.

IssueとPull Requestは日本語でも英語でも受け付けています。

## Rules for AI coding assistants / AIコーディングアシスタントのルール

AI agents MUST NOT add Signed-off-by tags. Only humans can legally certify the origin
of the source code. AI agents are only tools and do not absolve the human submitter
of their responsibility:

* Reviewing all AI-generated code
* Ensuring compliance with licensing requirements
* Taking full responsibility for the contribution

An `Assisted-by` tag MUST NOT be added. That information is irrelevant to the
contribution of the human contributor.

AIエージェントはSigned-off-byタグを付けてはなりません。ソースコードの出所を法的に証明できるのは
人間だけです。AIエージェントは道具にすぎず、提出者である人間の次の責任を免除するものではありません:

* AIが生成したすべてのコードのレビュー
* ライセンス要件を満たしていることの確認
* コントリビューションに対するすべての責任

`Assisted-by`タグは付けてはなりません。この情報は人間のコントリビューターによる貢献とは関係が
ありません。
