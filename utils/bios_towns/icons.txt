# FM Towns system icons of the HLE system ROM.
#
# 128 icons of 32 x 32 pixels in slot order. The system ROM holds them at
# FFFE8000h, 256 bytes per icon: a 128-byte pattern and a 128-byte mask, one
# bit per pixel, most significant bit first. A mask bit 1 keeps the screen
# pixel. A pattern bit 1 draws a black pixel.
#
# '#' black pixel (pattern 1, mask 0), '.' white pixel (pattern 0, mask 0),
# '-' transparent pixel (pattern 0, mask 1).
#
# The art is original. It follows the slot assignment of the real system ROM.
